# COMP 250 Notes

Reading notes from COMP 250, Research Writing: Open Source Tools and Techniques, at Loyola University Chicago (Fall 2026).

Each note follows the Zettelkasten approach: one source, one idea, written in my own words, and connected to related notes. The goal is to turn reading into a set of linked arguments I can draw on later, not a pile of summaries. Most notes so far deal with AI: how reliable it is, how it's changing education, and the industry pressures behind it.

## Repository Layout

```
COMP250-notes/
├── /first-note-collection        # One Markdown file per note, named topic-source-NN.md
└── README.md
```

## Note Template

Every note uses the same fields:

```markdown
# Title:        The idea the note captures
# Date:         When I wrote the note
# Source:       Full citation (Chicago style, generated from Zotero)
# Valuable Quote:  One short passage worth keeping
# Insight:      My analysis in my own words
# Keywords:     Terms for searching across notes
# Links:        Related notes in this repo
```
