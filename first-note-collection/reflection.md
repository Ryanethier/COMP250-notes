# First Note Collection - Reflection

# Date: September 11th, 2026

To start, I think this first note collection was a real treat to work on/with. There were some hiccups along the way for sure but that's what learning is all about and I'm feeling accomplished with the collection I put together.

In some form of humor, I initially thought we were to write one note per source so up until early this week I was writing a summary note per source. Quickly I realized that this wasn't the objective or way to approach this assignment and process. A big majority of this week's work was re-reading the material I had already read and "summarized" and then create either one or two additional notes on that source.

I chose to include several other sources that weren't part of class material but I felt they had some relation to the texts and articles we were assigned. Most of my sources revolved around AI or tech in some regard.

Along the way I found myself getting more comfortable within the command line and to my surprise I actually enjoy it. Prior to this course I never considered using the command line as a writing environment but I'm surprised to find that it's quite freeing and distraction free. I wrote my first note or two using nano and quickly realized that if I wanted to be part of the culture I'd have to learn VIM. I spent at least an hour this week reading up on VIM and watching tutorials. How can a writer not reflect on the very canvas they choose to craft their ideas? 

Looking back at the collection as a whole, the question I kept coming back to without really planning it was where these AI systems fail and who's responsible for it when they do. I found that Reuters and Medium were both great sources for these topics, especially when it's coming from an actual tech "worker". 

In future note collections there are a few things I'd like to improve or do better. One, I'd like to spend less time worrying about the "formatting" requirements and more time just writing and jotting down my thoughts as I read the articles, watch the videos, etc. Two, I'd like to improve my connections between notes and have keywords overlap a bit more.

As far as my involvement with AI, I used it as an organization tool and not a writing tool. I had Uncle Claude create the keyword frequency table and 
organize my notes and formatting. I also used Claude Code to parse through my notes and perform a spell check.
